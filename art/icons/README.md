# 레벨업 카드 아이콘

여기에 `<id>.png`를 넣으면 레벨업 카드 윗칸(1번 칸)에 자동으로 뜬다. 없으면 빈 칸으로 나온다.
칸 크기는 72×72 픽셀이다. 같은 크기나 정수배(144×144)로 그리면 깔끔하다.

| smoke.png | 연기탄 |
| bomb.png | 기폭수리검 |
| wraps.png | 손목 붕대 |
| fur.png | 검은 털 |
| collar.png | 스파이크 목걸이 |
| charm.png | 주황 부적 |
| legs.png | 단련된 다리 |
| ears.png | 긴 귀 |
| stealth.png | 그림자 은신 (특수 스킬) |

| heal.png | 당근 (회복) |
